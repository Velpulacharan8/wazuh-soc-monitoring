# Wazuh SOC Monitoring Lab

A hands-on Security Operations Center (SOC) lab built using Wazuh SIEM to demonstrate endpoint monitoring, Windows security event detection, authentication monitoring, and File Integrity Monitoring (FIM).

## 🛡️ Project Overview

This project simulates a real-world SOC monitoring environment using Wazuh.

The lab focuses on collecting and analyzing security events from a Windows endpoint and detecting suspicious activities through the Wazuh dashboard.

## 🔧 Technologies Used

- Wazuh SIEM
- Wazuh Agent
- Windows Endpoint
- Ubuntu Server
- VirtualBox
- Windows Security Event Logs
- File Integrity Monitoring (FIM)

## 🎯 Objectives

- Deploy and configure Wazuh SIEM
- Connect a Windows endpoint to Wazuh
- Monitor Windows security events
- Detect authentication-related activity
- Monitor file changes using FIM
- Investigate security alerts through the Wazuh dashboard
- Practice SOC analyst monitoring and investigation workflows

## 🔍 Security Monitoring

The lab demonstrates:

### Authentication Monitoring
Monitoring Windows authentication events and identifying failed login activity.

### Windows Security Monitoring
Collecting and analyzing Windows security logs through the Wazuh agent.

### File Integrity Monitoring
Monitoring selected files and detecting unauthorized or unexpected file modifications.

### Alert Investigation
Reviewing generated security alerts in the Wazuh dashboard and analyzing event details.
